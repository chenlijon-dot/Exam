目前 1-1～1-4 已正式接入章節題庫；困難題中的 `type: "handwriting"` 為正式計分題型。

```text
選擇題
→ 前端即時對答案

手寫題
→ exam-handwriting.js
→ 完整 Web Canvas 工具鏈
→ Firebase App Check / Firebase AI Logic
→ Gemini 判讀答案與計算過程
→ correct / incorrect / unclear
→ 納入同一次正式成績
```

其中 1-1、1-2 已使用自有 `number-line` SVG renderer 產生部分自編數線題；正式教材／正式試題原圖仍維持 evidence 優先。

## 維護規則

後續數學教材、各校段考、自編題與 AI curriculum，均優先依本目錄進行章節定位。若不同版本課本章節名稱或順序不同，先核對實際教材，再修改 catalog；不可只依模型記憶改動。

# 國中線上題庫 Exam

> 專案狀態與工作進度文件。後續新增科目、學期、章節、題庫、歷屆試題、錯題診斷或資料結構時，請同步更新本 README。
>
> 最後更新：2026-09-13

## 1. 專案目標

這個專案要逐步建立一套可在手機與電腦使用的「國中線上題庫」。

主要方向：

- 一般題庫依「科目 → 年級／學期 → 章節 → 難度」進入。
- 主選單另外提供「歷屆考題」，整理國中基測／教育會考歷屆試題。
- 一般章節題庫可建立簡易、中等、困難等不同層級題目。
- 作答後立即判定答案，可顯示正確答案與詳解。
- 保存作答紀錄與錯題，供後續複習。
- 一般章節錯題可交由 AI 依「該章課文知識基準」分析真正的弱點，而不是只做一般性評論。
- 歷屆考題保留原始題號、選項順序、題組脈絡與附圖，不因目前課綱而改寫原題。
- 題庫內容與私人學習紀錄分離：公開網站不存放私人學習資料或 API Secret。

## 3. 科目、章節與歷屆題分類規則

一般章節題庫依下列層級管理：

```text
科目
└─ 年級／學期
   └─ 章節
      └─ 題庫難度
         └─ 題目
```

目前五大科目：

```text
國文
英文
數學
自然
社會
```

每一科再依：

```text
七年級上學期（一上）
七年級下學期（一下）
八年級上學期（二上）
八年級下學期（二下）
九年級上學期（三上）
九年級下學期（三下）
```

分類時應優先依「實際使用的教材／課本章節」建置，不先憑印象一次填滿所有章節。

歷屆考題使用不同分類軸：

```text
歷屆考題
└─ 考試制度
   └─ 年度
      └─ 次別（若該制度有多次測驗）
         └─ 科目
            └─ 題目
```

目前考試制度先分：

```text
國中基本學力測驗（基測）
國中教育會考
```

歷屆題不應強迫塞進單一課文章節。未來可額外替每一題加上「對應科目／學期／章節／concept ID」標籤，讓跨年度錯題也能回到章節弱點分析。

## 4. 已完成：自然一上「科學方法」題庫

目前第一個可完整作答的一般章節為：

```text
自然
└─ 七年級上學期（一上）
   └─ 第 1 章 科學方法
```

每個難度 20 題，每題 5 分，滿分 100 分。

### 簡易

以基本觀念為主：

- 科學方法基本步驟
- 觀察、問題、假說、結論
- 操縱變因、應變變因、控制變因
- 簡單的實驗組／對照組概念

### 中等

以情境應用為主：

- 實驗組與對照組
- 變因判讀
- 實驗結果判讀
- 科學方法在情境題中的應用

### 困難

以分析能力為主：

- 資料判讀
- 實驗設計缺陷
- 控制變因
- 結論是否被資料支持
- 實驗結果與假說的關係

## 5. 已完成：第一份歷屆考題

目前已正式匯入：

```text
歷屆考題
└─ 國中基本學力測驗（基測）
   └─ 90 年度
      └─ 第一次
         └─ 國文科：46 題
```

題目依使用者提供的試題列印版還原，並整理成網站可作答的結構化題庫。

### 目前支援內容

- 完整 46 題題號。
- 保留原始 A／B／C／D 選項順序。
- 支援單題與題組文章。
- 支援題目附圖顯示。
- 第 29 題書法圖已建立獨立圖片資產。
- 第 30 題書信格式圖已建立獨立圖片資產。
- 題組文章可直接在題目卡上方呈現。
- 可交卷、標示答對／答錯、顯示答案與詳解欄位。
- 可重新作答。
- 可從考卷返回「90 年度第一次 → 科目」頁面。

### 歷屆題評量方式

歷屆考題不使用一般章節題庫的「分數制」。

例如 46 題考卷應呈現：

```text
答對 37 / 46 題
正確率 80.4%
答錯 9 題
未答 0 題
```

也就是：

```text
歷屆考題 → 答對題數／總題數 + 正確率
一般章節題庫 → 依題庫設定使用分數制
```

歷屆題不顯示「每題 5 分」或「滿分 100 分」。

### 歷屆題選項規則

一般自編題庫可隨機排列選項，但歷屆考題必須保留原始選項位置。

目前透過：

```text
preserveOptionOrder: true
fixedOptions: true
```

避免歷屆原題的 A／B／C／D 因隨機排列而改變。

### 歷屆題目前的資料路徑

```text
past-exams/bct/90/first/chinese.json
```

圖題資產：

```text
past-exams/bct/90/first/assets/q29-calligraphy.svg
past-exams/bct/90/first/assets/q30-letter.svg
```

## 6. 題庫目前已有的功能

### 作答

一般章節題庫：

- 每章可依設計選「簡易／中等／困難」。
- 科學方法目前各 20 題。
- 作答進度即時顯示。
- 可以有未作答題目再交卷。
- 一般題庫選項可重新隨機排列。
- 隨機排列後會同步重算正確答案位置，不影響評分。

歷屆考題：

- 可支援不同總題數，目前已實測 46 題。
- 保留正式題號。
- 保留原始選項順序。
- 支援題組文章 `intro`／`introLabel`。
- 支援題目附圖 `image`／`imageAlt`。

### 評量與詳解

- 交卷後標示正確答案。
- 正確答案以綠色顯示。
- 本次選錯答案以紅色顯示。
- 可切換顯示／隱藏詳解。
- 可以重新作答。
- 一般題庫可使用分數制。
- 歷屆考題使用「答對題數／總題數 + 正確率」，不以分數呈現。

### 作答紀錄

目前紀錄格式已擴充為可區分：

```text
practice   → 一般章節題庫
past-exam  → 歷屆考題
```

一般題庫紀錄：

- 科目／章節／難度
- 分數
- 答對、答錯、未答
- 作答時間

歷屆題紀錄：

- 考試制度
- 年度
- 次別
- 科目
- 答對題數／總題數
- 正確率
- 答錯、未答
- 作答時間

未作答與答錯維持分開計算。

### 錯題複習

- 只記錄「有作答但答錯」的題目。
- 未作答不列入錯題。
- 顯示學生最近寫錯的答案與正確答案。
- 累積同一題的錯誤次數。
- 歷屆題錯題可保留年度／次別／科目／原始題號。
- 歷屆題若屬題組，可保存題組文章供錯題回顧。
- 歷屆題若有附圖，可在錯題回顧中顯示圖片。
- 可清除本機錯題紀錄；清除錯題不等於刪除完整作答紀錄。

## 7. AI 錯題診斷

目前錯題分析使用 Google Gemini。

目前後端模型：

```text
gemini-3.5-flash-lite
```

AI 不只接收「題目／學生錯答／正確答案」，還會讀取該章節的課程知識基準，再做判定。

目前已建立 AI 診斷的正式章節為：

```text
自然一上 → 科學方法
```

目前科學方法章的知識基準：

```text
Exam-Record/curriculum/science-method.json
```

內容包含：

- 本章核心流程
- 課本概念與定義
- 三種變因
- 實驗組／對照組
- 實驗紀錄與資料分析
- 假說與結論
- 常見迷思
- 診斷分類
- AI 診斷限制

### AI 診斷原則

AI 必須：

- 先看章節知識基準，再看學生錯題。
- 只指出錯題真正支持的弱點。
- 不可因一題錯就說整章不熟。
- 不可自行擴充成高中、大學程度內容。
- 錯題少時不得硬湊三個弱點。
- 用國一學生看得懂的繁體中文。
- 避免研究報告式或過度學術的語言。
- 優先說清楚「這次混淆了什麼、兩者差在哪、下次如何判斷」。
- 複習建議應是 5～10 分鐘可執行的小動作。

目前輸出格式大致為：

```text
重點診斷
...

最需要加強
① ...
② ...（有證據才出現）

今天怎麼複習
① ...
② ...
③ ...
```

### 歷屆考題的 AI 診斷狀態

目前歷屆考題已可進入作答紀錄與錯題系統，但**暫不直接送入科學方法的 AI 診斷**。

原因：歷屆國文題尚未建立專屬 curriculum／concept mapping。若直接套用自然科知識基準會造成錯誤診斷。

未來要啟用歷屆題 AI 分析，應先完成：

```text
歷屆題 → 科目／章節標籤 → concept ID → 對應 curriculum
```

- 不可寫入 repository 原始碼。
- 不可寫入 README。
- 不可貼到 ChatGPT 對話。
- 前端目前只存於 `sessionStorage`。

Gemini API key：

- 不可放進公開 GitHub Pages JavaScript。
- 存在私人 `Exam-Record` 的 GitHub Actions Secret。
- Secret 名稱：`GEMINI_API_KEY`。

README 不應紀錄任何 token、password 或 API key 實值。

## 11. 建置原則

### A. 先確認教材，再建立章節

新增一般章節時應先取得實際課本／講義內容，再確認：

- 科目
- 年級
- 上／下學期
- 章節名稱
- 範圍
- 核心概念

不要先憑印象建立完整章節表。

### B. 題目不是只求數量

每一章一般題庫應盡量覆蓋：

```text
基本記憶
→ 概念理解
→ 情境應用
→ 資料判讀
→ 高階錯誤辨識／實驗設計
```

### C. AI 診斷不能只靠模型常識

每一章正式加入 AI 錯題診斷前，最好建立自己的 curriculum knowledge base，例如：

```text
curriculum/<chapter-id>.json
```

AI 應以該檔案為本章判定基準。

### D. 未答不等於答錯

整個系統維持：

```text
答對
答錯
未答
```

三種狀態分開處理。

未答不得進錯題清單，也不得被 AI 當成錯誤觀念證據。

### E. 選項隨機規則依題型而定

一般自編題庫：

- 選項可重新排列。
- 正確答案必須跟著重新定位。
- 錯題分析應使用答案文字／概念，不要把 A、B、C、D 當成長期識別依據。

歷屆考題：

- 預設保留原始選項順序。
- 不任意改變原題 A／B／C／D。
- 圖題或選項與圖片位置有關時尤其不得隨機排列。

### F. 歷屆考題必須保留原始來源脈絡

歷屆考題與自編章節題庫不同：

- 原始題目不能為了符合目前課本而任意改寫。
- 必須保留考試制度、年度、次別、科目、題號與來源脈絡。
- 課綱對應與章節分類應放在 metadata，不改動原題。
- 題目與答案匯入後要經過人工核對再標示為可用。
- 題目若含必要圖像，應建立獨立圖片資產並由題庫資料引用。
- 題組文章應保留完整上下文，不只抽出單題題幹。

### G. 歷屆考題不使用一般模擬考分數

歷屆考題統一以：

```text
答對題數 / 總題數
正確率 %
```

作為主要成績呈現。

不要因為一般題庫每題 5 分，就把不同題數的歷屆試卷硬換算成同一套分數。
